# Gallo · Abogados

Landing page en español con servicios jurídicos generales, diseño adaptable y formulario demostrativo.

## Diseño

Azul noche, marfil y oro champán. Portada con fotografía en arco, tipografía editorial y servicios en filas.

## Uso

Abre `index.html` en el navegador. Para servirla localmente, ejecuta `node preview.cjs` y visita http://127.0.0.1:4173.

## Contacto

El formulario valida los campos y muestra una confirmación de demostración. No envía ni almacena datos. Configura un backend y el aviso de privacidad antes de recibir solicitudes reales. El nombre y los servicios son contenido ilustrativo pendiente de confirmación.

Las fuentes se cargan desde Google Fonts y la fotografía desde Unsplash.
